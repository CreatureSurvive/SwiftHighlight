# Changelog

## 1.0.0

- Initial release: grammar engine (bytecode VM with first-byte dispatch, automatic
  possessification and per-line step budgets), 33 built-in languages with embedding, 13 themes,
  VS Code and TextMate theme import, incremental `HighlightSession`, and renderers for SwiftUI
  (`AttributedString`, `CodeView`), UIKit/AppKit (`NSAttributedString`), HTML/CSS and ANSI.
